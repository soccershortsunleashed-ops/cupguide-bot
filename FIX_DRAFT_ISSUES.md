# 🔧 Исправления проблем с черновиком

## ✅ Что исправлено:

### 1. Проверка на дубликаты:
   - Добавлена умная проверка - сравниваются ключевые части (роль, организация, описание)
   - Проверяется начало formatted_info (300 символов)
   - Дублирующаяся информация не добавляется повторно

### 2. Сохранение в правильное поле:
   - Информация из анализа сохраняется в `draft_info` (черновик)
   - `extracted_info` остается для обработанной информации

### 3. Защита от исчезновения:
   - Черновик НЕ обновляется при автообновлении
   - Обновляется только поле "Краткая информация"
   - Черновик обновляется только если:
     - Поле пустое (первая загрузка)
     - Появилась новая информация (добавляется только новая часть)

### 4. Автообновление:
   - Интервал увеличен до 10 секунд
   - Черновик полностью защищен от автообновления
   - Обновляется только поле "Краткая информация"

## 📋 Логика работы:

1. **При анализе сообщений:**
   - Информация форматируется
   - Проверяется на дубликаты
   - Если не дубликат - добавляется в `draft_info`
   - Если дубликат - пропускается

2. **При открытии карточки:**
   - Черновик загружается один раз при открытии
   - При автообновлении черновик НЕ трогается
   - Обновляется только "Краткая информация"

3. **При редактировании:**
   - Если пользователь редактирует черновик - автообновление пропускается
   - Введенный текст сохраняется

## 🎯 Результат:

- ✅ Информация попадает в черновик автоматически
- ✅ Дубликаты не добавляются
- ✅ Черновик не исчезает при редактировании
- ✅ Автообновление не мешает работе
