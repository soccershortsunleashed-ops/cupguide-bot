help Справка по кнопкам
Кнопки в заголовке списка контактов:
Обновить список контактов

Обновляет список контактов из базы данных без обращения к WhatsApp API.

Обновить все из WhatsApp

Массовое обновление всех контактов через Green API. Получает: имя в WhatsApp, аватар, WhatsApp ID, email, категорию бизнеса, описание, информацию о продуктах (для бизнес-аккаунтов), статус регистрации в WhatsApp и другую доступную информацию. Может занять некоторое время.

Справка

Открывает это окно со справкой по всем кнопкам интерфейса.

Кнопки действий для каждого контакта:
Информация о контакте

Открывает карточку контакта с подробной информацией: инсайты, история сообщений, извлеченная информация об авторе.

Отправить сообщение

Открывает окно для отправки сообщения контакту через WhatsApp.

Редактировать

Открывает форму для редактирования имени, телефона и группы контакта.

Обновить из WhatsApp

Обновляет информацию о конкретном контакте из WhatsApp: имя, аватар, WhatsApp ID и другую доступную информацию.

Удалить

Удаляет контакт из базы данных. Действие необратимо.

Другие кнопки:
Рассылка по группе

Отправляет сообщение всем контактам выбранной группы через WhatsApp (используется Green API).

Переместить контакты

Перемещает выбранные контакты в другую группу. Появляется при выборе контактов через чекбоксы.

Массовое удаление

Удаляет все выбранные контакты. Появляется при выборе контактов через чекбоксы.

help Справка по кнопкам - Сообщения
Кнопки в заголовке страницы:
Перезагрузить медиа

Перезагружает все медиа файлы (изображения, видео, документы) из каналов Telegram и WhatsApp групп. Используется, если медиа файлы не загрузились или были удалены.

Обновить

Обновляет список сообщений из всех подключенных каналов (Telegram и WhatsApp). Загружает новые сообщения и обновляет существующие.

Действия с сообщениями:
Опубликовать

Опубликовывает переписанное сообщение в целевой канал Telegram. Кнопка появляется после выполнения "Рерайт" для сообщения.

Рерайт

Переписывает текст сообщения с помощью ChatGPT. Результат отображается в правой части карточки сообщения.

help Справка по кнопкам - Каналы
Форма добавления канала:
Платформа

Выберите платформу для мониторинга: Telegram или WhatsApp.

Ссылка или Username

Введите ссылку на канал (например, https://t.me/channel) или username (например, @channel). Для WhatsApp групп укажите ID группы.

Тип

Источник (Source) - канал для мониторинга и получения сообщений. Целевой (Target) - канал для публикации переписанных сообщений.

Кнопка "Добавить"

Добавляет новый канал в список для мониторинга или публикации.

Действия с каналами в списке:
Удалить канал

Удаляет канал из списка. Канал перестанет мониториться, но ранее загруженные сообщения останутся в базе данных.
