## 🎯 Функционал

- **FSM воронка**: Пошаговый скрининг через кнопки (Q1/Q2/Q3)
- **LLM скоринг**: Оценка лидов A/B/TRASH через MegaLLM
- **Детерминированный скоринг**: Страховка LLM по формуле
- **Маршрутизация**: Разные сценарии для A/B/TRASH лидов
- **Автопостинг**: Публикация в 28 каналов каждый час
- **Уведомления**: Мгновенные уведомления владельцу о новых лидах
- **Аналитика**: Статистика воронки и конверсий

## 🚀 Запуск

### 1. Установка зависимостей

```bash
cd freelance_bot
pip install -r requirements.txt
```

### 2. Настройка окружения

```bash
cp .env.example .env
# Отредактируйте .env файл
```

Обязательные переменные:
- `FREELANCE_BOT_TOKEN` - токен бота от @BotFather
- `MEGALLM_API_KEY` - ключ MegaLLM API
- `OWNER_TELEGRAM_ID` - ваш Telegram ID для уведомлений

### 3. Запуск бота

```bash
python bot.py
```

## 📊 Скоринг

### LLM Скоринг (MegaLLM)
- Использует system/developer промты из ТЗ
- Возвращает JSON с grade, score, reason, must_have, next_questions, bot_reply

### Детерминированный скоринг (страховка)
Баллы:
- Цель "продажи/заявки" +20, "лиды/поддержка" +10, "просто бот" -30
- Боль "оплата/интеграции/диалог" +20, "хаос" +5, "вход" +10
- Контекст "после конструктора" +15, "есть CRM" +20, "с нуля" +10
- Наличие чека +15
- Конкретика (ниша+продукт) +15
- Токсичность/демпинг -40

Пороги: A ≥ 70, B 40-69, TRASH < 40

## 🔔 Уведомления

- **A-лиды**: Мгновенно (приоритет HIGH)
- **B-лиды**: Мгновенно (приоритет MEDIUM)
- **TRASH**: По настройке (приоритет LOW)
- **Тихие часы**: 23:00 - 08:00 (кроме A-лидов)

## 📡 API Endpoints

```
GET  /api/leads/              - Список лидов
GET  /api/leads/stats         - Статистика воронки
GET  /api/leads/{id}          - Лид по ID
POST /api/leads/              - Создать лида
PUT  /api/leads/{id}          - Обновить лида
PATCH /api/leads/{id}/status  - Изменить статус
GET  /api/leads/{id}/events   - События лида
GET  /api/leads/{id}/conversation - История диалога
POST /api/leads/{id}/application  - Создать заявку
```

## 🔗 Deep-link трекинг

Формат: `https://t.me/{bot}?start=src_ch_{channelId}_p_{postId}`

Позволяет отслеживать источник лида из автопостинга.
