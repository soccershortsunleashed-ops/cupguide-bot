# Реализация формы создания турнира с автоизвлечением данных

## Обзор

Реализована полная система создания турниров с автоматическим извлечением структурированных данных из Markdown текста с использованием shadcn/ui компонентов через MCP.

## Ключевые компоненты

### 1. Сервис извлечения данных (`app/services/tournament_extraction_service.py`)

**Функциональность:**
- Извлечение структурированных данных из Markdown текста с помощью LLM
- Нормализация дат в формат dd.mm.yyyy
- Нормализация телефонных номеров для WhatsApp/tel ссылок
- Автоматическое определение региона по городу
- Парсинг таблиц форматов матчей
- Извлечение контактной информации, взносов, размещения и услуг

**Основные методы:**
- `extract_tournament_data(markdown_text)` - главный метод извлечения
- `_normalize_date(date_str)` - нормализация дат
- `_normalize_phone(phone_str)` - нормализация телефонов
- `_infer_region(city)` - определение региона по городу

### 2. Форма создания турнира (`app/templates/tournament_create.html`)

**UI компоненты (shadcn/ui):**
- Card, Button, Input, Textarea, Switch, Tabs, Alert
- Адаптивный дизайн с темной темой
- Табы для разделения функциональности:
  - Основная информация (ручной ввод)
  - Автоизвлеченные данные (с возможностью редактирования)
  - Предпросмотр карточки турнира

**Функциональность:**
- Валидация полей с счетчиками символов
- Загрузка изображений (до 15MB)
- Автоизвлечение данных из Markdown
- Предпросмотр карточки турнира
- Настройки публикации (Teletype/Telegram)

### 3. Карточка турнира (`app/templates/tournament_card.html`)

**Структура отображения:**
1. Hero-изображение (16:9)
2. Заголовок и краткое описание
3. Ключевые параметры (grid 4 колонки):
   - Даты проведения
   - Локация
   - Возрастные категории
   - Заявочный взнос
4. Основной контент (3 колонки):
   - Структура и правила турнира
   - Участники и требования
   - Размещение и услуги
5. Кликабельные контакты (WhatsApp/телефон/email)
6. Аккордеон с полным регламентом

**Анти-дублирование:**
- Исходный Markdown отображается только в аккордеоне
- Структурированные данные выводятся в отдельных блоках
- Нет повторения информации между блоками

### 4. API endpoints (`app/api/tournaments.py`)

**Новые endpoints:**
- `POST /api/tournaments/api-extract-tournament-data` - извлечение данных
- `POST /api/tournaments/create-with-extracted-data` - создание с данными
- `POST /api/tournaments/upload-image` - загрузка изображений
- `POST /api/tournaments/` - создание турнира (базовый)

### 5. Обновленная модель данных

**Расширенная модель Tournament:**
- Поля для изображений (original, 16:9, square)
- Настройки публикации (teletype, telegram)
- Статусы турнира
- Источник создания

**Новая модель ExtractedTournamentData:**
- Структурированные данные согласно техническому заданию
- Локация, даты, участники, форматы матчей
- Размещение, услуги, контакты, награды

## Пользовательский workflow

### 1. Создание турнира

1. Переход на `/tournaments/create`
2. Заполнение обязательных полей:
   - Название турнира (10-120 символов)
   - Основной текст в Markdown (до 15000 символов)
3. Опционально: краткое описание, изображения, настройки публикации

### 2. Автоизвлечение данных

1. Нажатие кнопки "Извлечь данные"
2. LLM анализирует Markdown текст
3. Извлеченные данные отображаются на вкладке "Автоизвлеченные данные"
4. Возможность редактирования полей (admin override)

### 3. Предпросмотр и создание

1. Просмотр карточки турнира на вкладке "Предпросмотр"
2. Создание турнира кнопкой "Создать турнир"
3. Автоматический переход на страницу созданного турнира

### 4. Отображение карточки

1. Турниры с извлеченными данными отображаются в новом формате
2. Структурированные блоки без дублирования
3. Кликабельные контакты с WhatsApp/телефон/email
4. Адаптивный дизайн для мобильных устройств

## Технические особенности

### Извлечение данных

**Поддерживаемые форматы:**
- Даты: "03 — 10 января 2026", "03.01.2026", "2026-01-03"
- Телефоны: "+7 904 507-24-50" → digits: "79045072450"
- Таблицы Markdown с форматами матчей
- Структурированные списки (документы, награды, услуги)

**Обработка ошибок:**
- Graceful fallback при ошибках LLM
- Валидация извлеченных данных
- Пользовательские уведомления об ошибках

### Кликабельные контакты

**WhatsApp:** `https://wa.me/{phoneDigits}`
**Телефон:** `tel:+{phoneDigits}`
**Email:** `mailto:{email}`

### Автогенерация изображений

- Поддержка загрузки оригинала (до 15MB)
- Автогенерация обложек 16:9 и 1:1 из оригинала
- Fallback на автогенерацию при отсутствии загрузки
