# Система мониторинга и анализа сообщений Telegram и WhatsApp

Комплексная платформа для автоматического мониторинга, сбора и интеллектуального анализа сообщений из Telegram-каналов и WhatsApp-групп с использованием искусственного интеллекта (поддержка различных LLM провайдеров: OpenAI, Google Gemini, Groq, MegaLLM и др.).

## 🎯 Основные возможности

### 1. Мониторинг каналов и групп

#### Telegram
- ✅ Автоматическое отслеживание новых сообщений в заданных каналах-источниках
- ✅ Поддержка множественных каналов одновременно
- ✅ Автоматическое обновление каждые 60 секунд
- ✅ Скачивание медиа-контента (фото, видео, документы)
- ✅ Сохранение метаданных сообщений (дата, автор, текст)

#### WhatsApp
- ✅ Мониторинг WhatsApp-групп через Green API
- ✅ Автоматическое получение новых сообщений в реальном времени
- ✅ Поддержка групповых чатов и личных сообщений
- ✅ Скачивание медиа-файлов (изображения, видео, аудио, документы)
- ✅ Извлечение информации об авторах сообщений
- ✅ Webhook-интеграция для мгновенных уведомлений

### 2. Интеллектуальный анализ контента

#### Анализ текста с помощью AI
- ✅ **Генерация саммари**: Автоматическое создание кратких выжимок из длинных сообщений
- ✅ **Рерайт текста**: Переписывание контента в журналистском стиле
- ✅ **Извлечение структурированных данных**: Автоматическое парсинг информации из неструктурированного текста
- ✅ **Анализ тональности**: Определение эмоциональной окраски сообщений
- ✅ **Классификация контента**: Автоматическая категоризация сообщений

#### OCR и анализ изображений (ОБНОВЛЕНО)
- ✅ **Многоуровневая система OCR**: Приоритетная система с автоматическим переключением между провайдерами
  - **Groq Vision** (приоритет 1): Быстрый и точный анализ с моделью `meta-llama/llama-4-scout-17b-16e-instruct`
  - **Gemini Vision** (приоритет 2): Бесплатный провайдер с квотными ограничениями
  - **OpenAI Vision** (приоритет 3): Резервный провайдер
  - **EasyOCR** (fallback): Локальное распознавание без API
- ✅ **Умное кэширование**: Автоматическое сохранение результатов OCR для повторного использования
- ✅ **Управление квотами**: Интеллектуальное переключение между провайдерами при исчерпании лимитов
- ✅ **Обработка ошибок**: Автоматическое восстановление после временных сбоев
- ✅ **Анализ изображений**: Понимание содержимого изображений с помощью Vision API

## 🏗️ Технические характеристики

  - **Groq** (рекомендуется): Быстрые модели с Vision API поддержкой
  - **MegaLLM**: Российский провайдер с конкурентными ценами
  - **OpenAI**: GPT-4o, GPT-4, GPT-3.5 с Vision API
  - **Google Gemini**: Бесплатный уровень с ограничениями
  - **Anthropic Claude**: Высокое качество анализа
  - Другие провайдеры (через OpenAI-совместимый API)

### OCR и Vision API (НОВОЕ)
- **Groq Vision**: `meta-llama/llama-4-scout-17b-16e-instruct` - основной провайдер
- **Gemini Vision**: `gemini-2.5-flash` - резервный бесплатный провайдер
- **OpenAI Vision**: `gpt-4o` - дополнительный провайдер
- **EasyOCR**: Локальное распознавание без интернета

### Интеграции
- **Telegram API**: Telethon для работы с каналами
- **WhatsApp Green API**: Мониторинг групп и получение сообщений
- **LLM API**: Множественные провайдеры с автоматическим переключением
- **Vision API**: Анализ изображений и OCR

### Хранение данных
- **JSON файлы**: Легковесное хранение данных
  - `channels.json` - список каналов
  - `messages.json` - сообщения Telegram
  - `whatsapp_messages.json` - сообщения WhatsApp
  - `contacts.json` - контакты
  - `tournaments.json` - карточки турниров
  - `monitored_chats.json` - отслеживаемые WhatsApp-группы
  - `llm_config.json` - конфигурация LLM провайдеров
  - `llm_keys.json` - ключи API для LLM
  - `ocr_status.json` - статус обработки OCR

## 📋 Установка и настройка

### Требования
- Python 3.10 или выше
- Аккаунт Telegram (для получения API ID и Hash)
- API ключ LLM провайдера (рекомендуется Groq или MegaLLM)
- Аккаунт Green API (для мониторинга WhatsApp)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка окружения

Создайте файл `.env` в корне проекта:

```env
# Telegram
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
TELEGRAM_PHONE=ваш_номер_телефона

# LLM Provider (рекомендуется Groq или MegaLLM)
OPENAI_API_KEY=ваш_ключ_api
# Примечание: несмотря на название, здесь может быть ключ от любого провайдера

# WhatsApp Green API (опционально)
GREEN_API_ID_INSTANCE=ваш_instance_id
GREEN_API_TOKEN=ваш_api_token
```

**Где получить:**
- Telegram API ID и Hash: [my.telegram.org](https://my.telegram.org)
- LLM API ключи:
  - **Groq** (рекомендуется): [console.groq.com](https://console.groq.com) - быстро и недорого
  - **MegaLLM**: [megallm.io](https://megallm.io) - российский провайдер
  - OpenAI: [platform.openai.com](https://platform.openai.com)
  - Google Gemini: [makersuite.google.com](https://makersuite.google.com)
  - Anthropic Claude: [console.anthropic.com](https://console.anthropic.com)
- Green API: [green-api.com](https://green-api.com)

### Запуск

1. **Запуск сервера**:
   ```bash
   python run.py
   ```
   Или используйте файл `start_server.bat` (Windows)

2. **Доступ к интерфейсу**:
   Откройте в браузере: [http://127.0.0.1:8000](http://127.0.0.1:8000)

3. **Первый вход**:
   - При первом запуске потребуется авторизация в Telegram
   - Введите номер телефона и код подтверждения
   - Если включена двухфакторная аутентификация, введите облачный пароль

4. **Настройка LLM провайдера**:
   - Перейдите в админ-панель
   - Выберите провайдера (рекомендуется Groq)
   - Введите API ключ и выберите модели
   - Для Vision API убедитесь, что выбрана поддерживающая модель

## 🚀 Использование

### Добавление каналов

1. Перейдите на вкладку **"Каналы"**
2. Нажмите **"Добавить канал"**
3. Введите username канала (например, `@channel_name`)
4. Выберите тип:
   - **Источник (Source)** - канал для мониторинга
   - **Целевой (Target)** - канал для публикации
5. Сохраните

### Добавление WhatsApp-групп

1. Перейдите на вкладку **"Группы"**
2. Введите ID группы (формат: `120363304781973950@g.us`)
3. Или используйте поиск по имени группы
4. Сохраните

### Работа с сообщениями

1. На вкладке **"Сообщения"** отображаются все новые посты
2. Нажмите **"Обновить"** для принудительной проверки новых сообщений
3. Для каждого сообщения доступны:
   - **Сгенерировать саммари** - краткая выжимка
   - **Рерайт** - переписывание в журналистском стиле
   - **Опубликовать** - отправка в целевой канал

### Анализ турниров (ОБНОВЛЕНО)

1. **Автоматическое обнаружение**: Система автоматически обнаруживает афиши турниров в сообщениях
2. **Множественные турниры**: Если в одной афише несколько турниров (разные даты/возраста), система создает отдельные карточки
3. **Просмотр результатов**: Перейдите на вкладку **"Турниры"** для просмотра всех карточек
4. **Содержимое карточек**:
   - Изображение афиши
   - Извлеченные данные с Markdown-форматированием
   - Структурированная информация (название, даты, место, контакты)
   - Ссылка на исходное сообщение
5. **Редактирование**: Вы можете редактировать карточки вручную
6. **Поиск и фильтрация**: Удобный поиск по датам, городам, возрастам

### Управление контактами

1. Перейдите на вкладку **"Контакты"**
2. Система автоматически создает контакты из сообщений
3. Для каждого контакта доступно:
   - **Обогатить** - получение дополнительной информации через WhatsApp API
   - **Редактировать** - ручное редактирование данных
   - **Просмотр инсайтов** - автоматически сгенерированные описания
   - **История сообщений** - все сообщения от контакта

### Настройка LLM провайдеров (НОВОЕ)

1. Перейдите в **Админ-панель**
2. Выберите вкладку **"LLM Конфигурация"**
3. Настройте провайдеров:
   - **Groq**: Рекомендуется для Vision API (`meta-llama/llama-4-scout-17b-16e-instruct`)
   - **MegaLLM**: Для текстового анализа (`llama3-8b-instruct`)
   - **Gemini**: Бесплатный вариант с ограничениями
4. Введите API ключи и выберите модели
5. Система автоматически переключается между провайдерами при исчерпании квот

## 🔧 Решение проблем

### Сообщения не приходят
- Нажмите кнопку **"Обновить"** в ленте
- Проверьте, что вы авторизованы (зеленый значок "Подключено")
- Убедитесь, что каналы добавлены правильно
- Перезапустите сервер

### Ошибка "database is locked"
- Полностью остановите сервер (Ctrl+C)
- Подождите несколько секунд
- Запустите сервер заново

### WhatsApp сообщения не загружаются
- Проверьте настройки Green API в `.env`
- Убедитесь, что группа добавлена в `monitored_chats.json`
- Проверьте логи в `logs/app.log`

### Проблемы с LLM API
- Проверьте, что ключ API указан в `.env` или в админ-панели
- Убедитесь, что выбранная модель поддерживает нужную функциональность
- Проверьте лимиты использования API
- Система автоматически переключится на резервный провайдер при исчерпании квот

### Проблемы с OCR
- Система автоматически попробует несколько провайдеров
- При проблемах с Groq Vision система переключится на Gemini или OpenAI
- В крайнем случае будет использован локальный EasyOCR
- Проверьте логи для диагностики конкретных ошибок

### Ошибки зависимостей
- Убедитесь, что установлена правильная версия blinker: `pip install blinker==1.6.3`
- Для PDF обработки установите: `pip install PyPDF2`
- Обновите все зависимости: `pip install -r requirements.txt --upgrade`
