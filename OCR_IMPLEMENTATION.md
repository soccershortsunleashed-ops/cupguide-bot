# Реализация OCR для анализа изображений

## ✅ Что сделано:

### 1. Создан сервис OCR (`app/services/ocr_service.py`)
   - Поддержка двух методов OCR:
     - **OpenAI Vision API** (приоритет) - использует GPT-4o для распознавания текста
     - **EasyOCR** (fallback) - локальное распознавание, если OpenAI недоступен
   - Автоматический выбор метода в зависимости от доступности

### 2. Обновлен анализ сообщений (`app/services/message_analysis_service.py`)
   - Добавлена обработка изображений в сообщениях
   - При обнаружении изображения автоматически извлекается текст через OCR
   - Распознанный текст добавляется к тексту сообщения для анализа LLM
   - Формат: `[Текст с изображения]: <распознанный текст>`

### 3. Обновлен сервис анализа авторов (`app/services/author_analysis_service.py`)
   - Добавлена передача `media_path` в сообщения для анализа
   - Информация в карточке контакта **заменяется** новой (не добавляется)
   - Это гарантирует актуальность данных в карточке

## 🔧 Как это работает:

1. **При получении сообщения с изображением:**
   - Изображение сохраняется в `app/static/media/`
   - Путь сохраняется в поле `media_path` сообщения

2. **При анализе автора:**
   - Система собирает все сообщения автора (включая с изображениями)
   - Для каждого сообщения с изображением:
     - Определяется путь к файлу
     - Вызывается OCR сервис для распознавания текста
     - Распознанный текст добавляется к тексту сообщения

3. **При анализе LLM:**
   - LLM получает объединенный текст: обычные сообщения + текст с изображений
   - Извлекается структурированная информация
   - Информация сохраняется в карточку контакта (заменяя старую)

## 📋 Требования:

### Для OpenAI Vision API (рекомендуется):
- ✅ Уже настроено: `OPENAI_API_KEY` в `.env`
- Использует модель `gpt-4o` для распознавания текста

### Для EasyOCR (альтернатива):
- Установка: `pip install easyocr`
- Требует загрузки моделей при первом запуске (может занять время)

## 🎯 Результат:

- ✅ Изображения (афиши) автоматически анализируются
- ✅ Текст с изображений распознается и используется в анализе
- ✅ Информация в карточке контакта обновляется актуальными данными
- ✅ Старая информация заменяется новой (не накапливается)

## 📝 Пример работы:

1. Андрей отправляет афишу турнира (изображение)
2. Система скачивает изображение
3. OCR распознает текст: "Кубок Территории Спорта, 12-16 декабря, Сочи..."
4. LLM анализирует текст и извлекает информацию:
   - tournament_name: "Кубок Территории Спорта"
   - city: "Сочи"
   - dates: "12-16 декабря"
5. Информация сохраняется в карточку контакта Андрея

## ⚠️ Важно:

- Информация в карточке **заменяется** новой, а не добавляется
- Это гарантирует актуальность данных
- Если нужно сохранять историю, можно изменить логику в `author_analysis_service.py`
