# ✅ Реализована функция "Черновик информации"

## 🎯 Что сделано:

### 1. Модель Contact обновлена:
   - Добавлено поле `draft_info` - черновик информации (сырые данные из анализа)
   - Поле `extracted_info` теперь используется для обработанной информации

### 2. Логика сохранения:
   - Вся информация из анализа сообщений сохраняется в `draft_info`
   - `extracted_info` остается для обработанной информации, которую пользователь редактирует

### 3. UI обновлен:
   - Добавлено поле "Черновик информации" - показывает `draft_info`
   - Поле "Краткая информация" - показывает `extracted_info` (обработанная информация)
   - Добавлена кнопка "Обработать информацию" рядом с черновиком

### 4. API endpoint:
   - `POST /contacts/{contact_id}/draft/process` - обрабатывает черновик через LLM
   - LLM структурирует информацию, убирает даты и ссылки
   - Результат сохраняется в `extracted_info`

### 5. JavaScript функции:
   - `processDraftInfo()` - обрабатывает черновик через LLM
   - `saveContactInsights()` - сохраняет оба поля (extracted_info и draft_info)
   - `loadContactInsights()` - загружает оба поля

## 📋 Как это работает:

1. **Анализ сообщений:**
   - Информация из анализа сохраняется в `draft_info`
   - Черновик накапливается с разделителями по времени

2. **Обработка черновика:**
   - Пользователь нажимает "Обработать информацию"
   - LLM обрабатывает черновик:
     - Игнорирует даты публикации
     - Игнорирует ссылки
     - Структурирует информацию
     - Убирает дубликаты
   - Результат сохраняется в `extracted_info`

3. **Редактирование:**
   - Пользователь может редактировать `extracted_info` вручную
   - При сохранении оба поля обновляются

## 🎨 Интерфейс:

- **Черновик информации** (верхнее поле) - сырые данные, автоматически обновляется
- **Кнопка "Обработать информацию"** - обрабатывает черновик через LLM
- **Краткая информация** (нижнее поле) - обработанная информация, редактируется вручную
- **Кнопка "Сохранить"** - сохраняет оба поля

## 💡 Преимущества:

- ✅ История сохраняется в черновике
- ✅ Обработанная информация отделена от сырых данных
- ✅ Можно вручную редактировать обработанную информацию
- ✅ Автоматическая обработка через LLM
- ✅ Удобная структуризация информации
