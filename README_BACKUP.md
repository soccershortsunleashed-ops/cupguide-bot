# Система резервного копирования

## Быстрый старт

### Создание бэкапа
```powershell
.\backup.ps1
```

### Восстановление из бэкапа
```powershell
.\restore.ps1
```

## Описание

Система состоит из двух PowerShell скриптов для резервного копирования и восстановления критических файлов проекта.

### backup.ps1

**Что делает:**
- Создает timestamped бэкап всех критических файлов проекта
- Сохраняет структуру директорий
- Автоматически очищает старые бэкапы (хранит последние 10)
- Выводит подробный отчет о процессе

**Что копируется:**
- `app/templates/index.html`
- `app/static/js/app.js`
- `app/static/css/style.css`
- `app/main.py`
- Все директории: `app/api`, `app/services`, `app/models`, `app/core`
- `requirements.txt`
- `.env` (конфигурация)

**Пример использования:**
```powershell
# Стандартный бэкап в папку 'backups'
.\backup.ps1

# Бэкап в custom директорию
.\backup.ps1 -BackupDir "my_backups"
```

### restore.ps1

**Что делает:**
- Показывает список доступных бэкапов с информацией
- Позволяет выбрать бэкап для восстановления
- Восстанавливает все файлы из выбранного бэкапа
- Требует подтверждения перед восстановлением

**Пример использования:**
```powershell
# Интерактивный выбор бэкапа
.\restore.ps1

# Восстановление конкретного бэкапа
.\restore.ps1 -BackupName "backup_2025-11-24_13-30-00"

# Восстановление из custom директории
.\restore.ps1 -BackupDir "my_backups"
```

## Рекомендации

1. **Создавайте бэкап перед важными изменениями**
   ```powershell
   .\backup.ps1
   ```

2. **Проверяйте список бэкапов периодически**
   ```powershell
   .\restore.ps1  # Просто посмотрите список, не восстанавливайте
   ```

3. **Бэкапы хранятся в директории `backups/`**
   - Автоматически удаляются старые (>10 штук)
   - Можно сохранить важные бэкапы отдельно

4. **Формат имени бэкапа:** `backup_YYYY-MM-DD_HH-mm-ss`

## Автоматизация

Чтобы автоматически создавать бэкап перед запуском приложения, создайте скрипт `start_with_backup.ps1`:

```powershell
# Создаем бэкап
.\backup.ps1

# Запускаем приложение
python -m uvicorn app.main:app --reload
```

## Восстановление после ошибки

Если что-то пошло не так:

1. Остановите приложение (Ctrl+C)
2. Запустите восстановление:
   ```powershell
   .\restore.ps1
   ```
3. Выберите нужный бэкап
4. Подтвердите восстановление
5. Перезапустите приложение

## Структура директории backups

```
backups/
├── backup_2025-11-24_13-30-00/
│   ├── app/
│   │   ├── templates/
│   │   ├── static/
│   │   ├── api/
│   │   ├── services/
│   │   └── ...
│   ├── requirements.txt
│   └── .env
├── backup_2025-11-24_14-00-00/
└── ...
```

## Устранение проблем

**Ошибка: "execution of scripts is disabled"**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Ошибка доступа к файлам:**
- Убедитесь, что приложение не запущено
- Проверьте права доступа к файлам

**Бэкапы занимают много места:**
- Старые бэкапы удаляются автоматически (хранится 10)
- Можно вручную удалить ненужные из `backups/`
