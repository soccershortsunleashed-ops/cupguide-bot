# Telegram Bot "ИИ-консультант по турнирам"

Telegram-бот для консультаций по спортивным турнирам с использованием MegaLLM и интеграцией с backend API.

## Возможности

- 🔐 **Обязательное согласие** на обработку данных
- 📱 **Запрос контакта** через Telegram API
- 🤖 **ИИ-консультант** на базе MegaLLM с tool calling
- 🏷️ **Автоматическое тегирование** интересов пользователей
- 📊 **Полное логирование** всех взаимодействий
- 🔍 **Поиск турниров** по различным критериям
- 📋 **Показ карточек** турниров
- ❓ **Ответы на вопросы** о турнирах

## Установка и настройка

### 1. Установка зависимостей

```bash
pip install aiogram openai httpx pydantic python-dotenv
```

### 2. Создание бота в Telegram

1. Найдите @BotFather в Telegram
2. Создайте нового бота командой `/newbot`
3. Получите токен бота

### 3. Настройка конфигурации

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Обязательные параметры:
- `TELEGRAM_BOT_TOKEN` - токен от BotFather
- `MEGALLM_API_KEY` - ключ API MegaLLM
- `BACKEND_URL` - адрес backend API

### 4. Настройка backend API

Убедитесь, что backend поддерживает следующие эндпоинты:

#### Турниры
- `GET /api/tournaments/search` - поиск турниров
- `GET /api/tournaments/{id}` - получение турнира
- `GET /api/tournaments/{id}/card` - карточка турнира
- `POST /api/tournaments/{id}/lead` - создание лида

#### Контакты
- `POST /api/contacts/upsert` - создание/обновление контакта
- `POST /api/contacts/{id}/tags/merge` - обновление тегов
- `DELETE /api/contacts/{id}` - удаление контакта

#### Логирование
- `POST /api/logs/message` - логирование сообщений
- `POST /api/logs/llm` - логирование LLM вызовов

## Использование

### Команды бота

- `/start` - Начать работу (согласие + контакт)
- `/help` - Справка по использованию
- `/tournaments` - Ближайшие турниры
- `/search` - Интерактивный поиск
- `/privacy` - Политика конфиденциальности
- `/delete_me` - Удаление данных пользователя

### Примеры запросов

```
Найди турниры 2016 г.р. в январе в СПб
Покажи карточку Zenit Cup
Сколько стоит участие?
Где проходит турнир?
До какого числа подавать заявку?
Хочу записаться на турнир
```

## FSM (Состояния пользователя)

1. **NEW** - Новый пользователь, показ согласия
2. **CONSENTED** - Согласие получено, запрос контакта
3. **ACTIVATED** - Контакт получен, доступ к функциям

## Тегирование интересов

Автоматическое извлечение интересов из диалога:

### Типы тегов
- `city` - город интереса
- `age_year` - год рождения
- `time_period` - временной период
- `format` - формат игры
- `budget` - бюджетные предпочтения
- `topic` - тема разговора

### Пример тегов
```json
{
  "add": [
    {"key": "city", "value": "Санкт-Петербург", "confidence": 0.95},
    {"key": "age_year", "value": "2016", "confidence": 0.98}
  ],
  "remove": [],
  "notes": "Поиск турниров для 2016 г.р. в СПб"
}
```

## Troubleshooting

### Частые проблемы

1. **Бот не отвечает**
   - Проверьте токен бота
   - Убедитесь, что бот запущен
   - Проверьте логи на ошибки

2. **Ошибки MegaLLM**
   - Проверьте API ключ
   - Убедитесь в доступности сервиса
   - Проверьте лимиты запросов

3. **Ошибки backend API**
   - Проверьте доступность backend
   - Убедитесь в правильности эндпоинтов
   - Проверьте формат данных

4. **Проблемы с FSM**
   - Очистите состояния: `/start`
   - Проверьте Redis (если используется)
   - Перезапустите бота

### Логи ошибок

```bash
# Поиск ошибок
grep ERROR bot.log
```
