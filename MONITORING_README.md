## Использование скриптов мониторинга:

### 1. `auto_monitor.py` - Полноценный мониторинг
```bash
python auto_monitor.py
```
Этот скрипт будет:
- Проверять .env файл каждые 3 секунды
- Читать новые строки из logs/app.log
- Обнаруживать проблемы с OPENAI_API_KEY
- Показывать статус в реальном времени

### 2. `watch_and_fix.py` - Простой мониторинг
```bash
python watch_and_fix.py
```
Более простой вариант мониторинга состояния .env файла

### 3. `test_config.py` - Тест конфигурации
```bash
python test_config.py
```
Проверяет, правильно ли загружается OPENAI_API_KEY

## Рекомендуемый workflow:

1. **Запустите сервер в одном терминале:**

   python app.py
